GPT-5.6 Terra API Pricing & Workload Cost Analysis

By Meng Guoying (mengg) · Review method · Corrections

The verified numbers: GPT-5.6 Terra (OpenAI) bills $2.00 per 1M input tokens, $12.00 per 1M output tokens, and $0.20 per 1M cached input tokens, inside a 1.05M context window. On a reference 200-step agent loop, that totals roughly $2.89 per task.

Engineering perspective & production reality

Terra occupies the balanced mid-tier bracket ($2/$12), positioned directly against Claude Sonnet 5. For teams already built on OpenAI's Responses or Assistants API, Terra delivers consistent code synthesis speed with moderate per-task burn. Keep an eye on cache-write billing (1.25x uncached rate) when frequently mutating system prompts.

Translating list rates into real engineering spend

List rates per million tokens can be deceiving because autonomous loops hit prompt caches repeatedly. Below are two concrete reference workloads calculating the exact dollar burn for GPT-5.6 Terra:

Scenario A — One 200-step autonomous agent task

A coding agent operates over 200 steps with a fixed 40,000-token prefix (system instructions, tool declarations, repository map). The prefix is cached on step 1 and re-read on the remaining 199 steps, producing 500 output tokens per step. For OpenAI, cache writes bill at 1.25x the uncached input rate.
