Gemini 4 Carbon API Pricing & Workload Cost Analysis

By Meng Guoying (mengg) · Review method · Corrections

The verified numbers: Gemini 4 Carbon (Google DeepMind) bills $2.00 per 1M input tokens, $10.00 per 1M output tokens, and $0.10 per 1M cached input tokens, inside a 1M context window. On a reference 200-step agent loop, that totals roughly $1.80 per task.

Engineering perspective & production reality

Gemini 4 Carbon is Google's flagship heavy-reasoning model for deep coding, debugging, and cyber-defense workflows. Introductory pricing ($2/$10) runs through November 30, 2026 before moving to standard $4/$20 rates on December 1, 2026.

Translating list rates into real engineering spend

List rates per million tokens can be deceiving because autonomous loops hit prompt caches repeatedly. Below are two concrete reference workloads calculating the exact dollar burn for Gemini 4 Carbon:

Scenario A — One 200-step autonomous agent task

A coding agent operates over 200 steps with a fixed 40,000-token prefix (system instructions, tool declarations, repository map). The prefix is cached on step 1 and re-read on the remaining 199 steps, producing 500 output tokens per step. For Google DeepMind, cache writes bill at the input rate (per-hour cache storage is excluded).

Frequently asked questions

How much does Gemini 4 Carbon cost per million tokens?

Gemini 4 Carbon costs $2.00 per 1M input tokens and $10.00 per 1M output tokens, with cached input at $0.10 per 1M. Verified November 2026 against Google DeepMind's official pricing.

What is the context window of Gemini 4 Carbon?

Gemini 4 Carbon supports a 1M token context window, per Google DeepMind's documentation checked November 2026.

Does Gemini 4 Carbon support prompt caching?

Yes. Cached input tokens bill at $0.10 per 1M instead of the full input rate; cache writes bill at the input rate (per-hour cache storage is excluded).

When was this Gemini 4 Carbon price last checked?

In November 2026, against Google DeepMind's own pricing page: https://ai.google.dev/gemini-api/docs/pricing
