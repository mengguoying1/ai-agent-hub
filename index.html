How this site works

A smaller, auditable comparison is more useful than a long unverified list

The catalog below includes only entries we could verify against provider documentation on the stated date. Product availability and prices can change, so each row links to its source.

Official sources first

Prices and model limits come from provider documentation, not affiliate roundups.

Dates and caveats

Introductory prices, cache assumptions, and vendor-published benchmarks are labeled.
