Claude Sonnet 5 API Pricing & Workload Cost Analysis

By Meng Guoying (mengg) · Review method · Corrections

The verified numbers: Claude Sonnet 5 (Anthropic) bills $2.00 per 1M input tokens, $10.00 per 1M output tokens, and $0.20 per 1M cached input tokens, inside a 1M context window. On a reference 200-step agent loop, that totals roughly $2.69 per task.

Engineering perspective & production reality

Sonnet 5 is currently the default workhorse across the software engineering community. Anthropic's confirmation that the $2/$10 rate is standard (cancelling the scheduled increase to $3/$15) makes it roughly 60% cheaper than Opus while solving 85%+ of daily SWE-bench style issues cleanly. Its 1M token context window comfortably accommodates medium-to-large repositories without requiring complex hierarchical AST chunking.

Translating list rates into real engineering spend

List rates per million tokens can be deceiving because autonomous loops hit prompt caches repeatedly. Below are two concrete reference workloads calculating the exact dollar burn for Claude Sonnet 5:

Scenario A — One 200-step autonomous agent task

A coding agent operates over 200 steps with a fixed 40,000-token prefix (system instructions, tool declarations, repository map). The prefix is cached on step 1 and re-read on the remaining 199 steps, producing 500 output tokens per step. For Anthropic, cache writes bill at 1.25x the input rate.
