DeepSeek V4 Pro API Pricing & Workload Cost Analysis

By Meng Guoying (mengg) · Review method · Corrections

The verified numbers: DeepSeek V4 Pro (DeepSeek) bills $0.66 per 1M input tokens, $1.98 per 1M output tokens, and $0.022 per 1M cached input tokens, inside a 1M context window. On a reference 200-step agent loop, that totals roughly $0.40 per task.

Engineering perspective & production reality

V4 Pro is DeepSeek's high-reasoning model with an impressive 384K maximum output limit. Its extended availability makes it a strong candidate for complex mathematical reasoning, full-repo synthesis, and long-form technical documentation where standard 16K-32K output buffers are inadequate.

Translating list rates into real engineering spend

List rates per million tokens can be deceiving because autonomous loops hit prompt caches repeatedly. Below are two concrete reference workloads calculating the exact dollar burn for DeepSeek V4 Pro:

Scenario A — One 200-step autonomous agent task

A coding agent operates over 200 steps with a fixed 40,000-token prefix (system instructions, tool declarations, repository map). The prefix is cached on step 1 and re-read on the remaining 199 steps, producing 500 output tokens per step. For DeepSeek, cache writes bill at the standard input rate.

ComponentCalculationCost
Cache write (once)40,000 tokens × $0.66 / 1M$0.03
Cache reads199 × 40,000 × $0.022 / 1M$0.18
Output200 × 500 × $1.98 / 1M$0.20
Total per task$0.40

A team runs a production service processing 50M fresh input tokens, 150M cached input tokens, and 10M output tokens through DeepSeek V4 Pro per month:

Frequently asked questions

How much does DeepSeek V4 Pro cost per million tokens?

DeepSeek V4 Pro costs $0.66 per 1M input tokens and $1.98 per 1M output tokens, with cached input at $0.022 per 1M. Verified November 2026 against DeepSeek's official pricing.

What is the context window of DeepSeek V4 Pro?

DeepSeek V4 Pro supports a 1M token context window, per DeepSeek's documentation checked November 2026.

Does DeepSeek V4 Pro support prompt caching?

Yes. Cached input tokens bill at $0.022 per 1M instead of the full input rate; cache writes bill at the standard input rate.
