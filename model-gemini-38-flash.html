Gemini 3.8 Flash API Pricing & Workload Cost Analysis

By Meng Guoying (mengg) · Review method · Corrections

The verified numbers: Gemini 3.8 Flash (Google DeepMind) bills $0.75 per 1M input tokens, $3.75 per 1M output tokens, and $0.075 per 1M cached input tokens, inside a 1M context window. On a reference 200-step agent loop, that totals roughly $0.97 per task.

Engineering perspective & production reality

Gemini 3.8 Flash remains a fast, cost-effective agent engine at its $0.75/$3.75 introductory rate through December 31, 2026 (stepping up to $1.50/$7.50 on January 1, 2027).

Translating list rates into real engineering spend

List rates per million tokens can be deceiving because autonomous loops hit prompt caches repeatedly. Below are two concrete reference workloads calculating the exact dollar burn for Gemini 3.8 Flash:

Scenario A — One 200-step autonomous agent task

A coding agent operates over 200 steps with a fixed 40,000-token prefix (system instructions, tool declarations, repository map). The prefix is cached on step 1 and re-read on the remaining 199 steps, producing 500 output tokens per step. For Google DeepMind, cache writes bill at the input rate (per-hour cache storage is excluded).

Frequently asked questions

How much does Gemini 3.8 Flash cost per million tokens?

Gemini 3.8 Flash costs $0.75 per 1M input tokens and $3.75 per 1M output tokens, with cached input at $0.075 per 1M. Verified November 2026 against Google DeepMind's official pricing.

What is the context window of Gemini 3.8 Flash?

Gemini 3.8 Flash supports a 1M token context window, per Google DeepMind's documentation checked November 2026.

Does Gemini 3.8 Flash support prompt caching?

Yes. Cached input tokens bill at $0.075 per 1M instead of the full input rate; cache writes bill at the input rate (per-hour cache storage is excluded).
