DeepSeek V4.1 Flash API Pricing & Workload Cost Analysis

By Meng Guoying (mengg) · Review method · Corrections

The verified numbers: DeepSeek V4.1 Flash (DeepSeek) bills $0.15 per 1M input tokens, $0.60 per 1M output tokens, and $0.0030 per 1M cached input tokens, inside a 1M context window. On a reference 200-step agent loop, that totals roughly $0.09 per task.

Engineering perspective & production reality

DeepSeek V4.1 Flash offers industry-leading token economics at $0.15 input / $0.60 output and a microscopic $0.003 cache read rate. However, production engineers must plan around the weekday peak windows (01:00-04:00 and 06:00-10:00 UTC), during which rates double. Non-urgent batch workloads and background indexing jobs should be scheduled off-peak to lock in the sub-dollar price advantage.

Translating list rates into real engineering spend

List rates per million tokens can be deceiving because autonomous loops hit prompt caches repeatedly. Below are two concrete reference workloads calculating the exact dollar burn for DeepSeek V4.1 Flash:

Scenario A — One 200-step autonomous agent task

A coding agent operates over 200 steps with a fixed 40,000-token prefix (system instructions, tool declarations, repository map). The prefix is cached on step 1 and re-read on the remaining 199 steps, producing 500 output tokens per step. For DeepSeek, cache writes bill at the standard input rate.
